This repository contains an exploratory data analysis project focused on an automobile dataset, leveraging Matplotlib and Seaborn for rich statistical data visualizations[cite: 14].

---

## Dataset Notice
*Note: The dataset (`cars_ds_final.csv`) used in this project[cite: 14] can be found on Kaggle under automotive vehicle datasets.*

---

## Project Workflow & Visualizations
* **Data Exploration**: Loading and inspecting automotive records using Pandas.
* **Brand Distribution**: Visualizing the top 10 car brands by model and variant counts using Seaborn bar plots[cite: 14].
* **Fuel Type Analysis**: Examining the distribution of vehicles based on their fuel types[cite: 14].
* **Body Type Insights**: Plotting the frequency distribution of primary car body styles.
* **Web Application**: Interactive deployment interface built with Streamlit.
